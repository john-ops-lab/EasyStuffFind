# EasyStuffFind Web 设计系统

视觉概念生成于 2026-07-23，目标是中文、移动优先、安静可信的家庭工具。

## 核心方向

- 背景：纯白；左侧栏：冷灰 `#f7f9f8`。
- 主色：青绿色 `#078a78`；正文：深墨绿 `#14251f`。
- 容器：开放式列表和细分隔线，不使用卡片网格。
- 圆角：关键输入与操作面 10–14px；阴影只用于抽屉和模态框。
- 字体：macOS/中文系统无衬线；按钮和表单明确设定字号与字重。
- 动效：树节点选中、抽屉滑入；尊重 `prefers-reduced-motion`。

## 组件

- 顶栏：品牌、全局搜索、服务状态、token 设置。
- 位置树：合成“全屋”根节点，层级缩进，直接物品数。
- 物品列表：桌面表格、手机媒体行；照片保持 1:1。
- 编辑抽屉：名称、别名、位置、备注和当前照片替换。
- 批量栏：多选后只提供取消和批量移动。
- 底部导航：位置、物品、历史。

## 响应式

- `>760px`：左侧位置树 + 主列表，编辑抽屉从右侧进入。
- `≤760px`：位置树为侧滑面板，物品为紧凑媒体行，编辑抽屉从底部进入。
- 所有主要操作最小触摸高度 44px，无水平滚动。
