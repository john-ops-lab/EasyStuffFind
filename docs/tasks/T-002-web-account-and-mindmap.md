# T-002：Web 账号、脑图与缓存修复

- 状态：实现完成，本机验证通过
- 日期：2026-07-24

## 目标

- OpenClaw/Agent 保持长期 token 认证，浏览器改为单管理员账号登录。
- Web 登录保持 30 天并支持修改密码。
- 增加默认展示前两级、可逐级展开到物品详情的脑图。
- 修复前端资源更新后普通刷新仍可能使用旧文件的问题。

## 实现

- SQLite Schema v2 新增 `web_accounts`；v1 自动向前迁移且不改原业务表。
- 默认账号/密码 `admin/admin`，scrypt 哈希存储；30 天 HttpOnly、
  SameSite=Strict 的签名 Cookie；修改密码使旧会话失效。
- 原生 Web 脑图递归渲染位置和物品，点击物品打开详情弹窗。
- 首页使用 `Cache-Control: no-store`，静态资源强制重新校验，并使用
  `v0.2.0` 查询版本。
- 位置侧栏折叠 ID 保存在浏览器本地存储中，刷新页面后保持原折叠状态。

## 验证

- 18 项自动化测试通过，包含默认登录、Cookie 属性、改密、旧密码失效、
  v1→v2 保留原数据迁移和缓存响应头。
- 隔离服务桌面 1280×720、手机 390×844 真实浏览器验证通过。
- 真实浏览器验证父级折叠后刷新页面仍保持折叠，子位置继续隐藏。
- 本机常驻服务升级到 v0.2.0 / Schema v2 前已完成一致性备份；升级后健康检查、
  Agent token 自检、默认 Web 账号登录与会话验证通过。
