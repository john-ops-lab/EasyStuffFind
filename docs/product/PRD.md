# PRD：EasyStuffFind 家庭物品位置记录工具

最后更新：2026-07-24

## 1. 一句话描述

供个人或家庭在局域网内通过 OpenClaw/飞书和中文 Web 管理端记录、查询与整理物品当前位置的本地服务。

## 2. 目标用户与渠道

- 目标用户：同一家庭内使用 Web 管理账号的成员，以及持有长期 API token 的 OpenClaw。
- 主交互：飞书消息 → OpenClaw → EasyStuffFind REST API。
- 管理渠道：移动优先的中文 Web 界面。
- 部署：Mac mini 单容器常驻运行，不暴露公网。
- 不面向：多人协作组织、公共互联网用户或资产管理团队。

## 3. 本期范围

- 位置树增删改查、按路径自动创建、非空删除保护。
- 物品新建、精确 upsert、编辑、移动、删除、别名、备注。
- 一物一张当前位置实景照片，本地存储并随物品删除。
- 名称/别名模糊查询，返回唯一、多候选或无结果。
- 物品移动历史和按位置反查。
- 中文移动优先 Web 管理界面，包含位置树、物品脑图和单管理员账号。
- `/api/v1` REST API、长期 token 认证、短时照片签名 URL。
- Docker Compose 单命令启动、健康检查、闭环自检。
- 面向人和 Agent 的安装、运行、备份恢复与 OpenClaw Skill 文档。
- 本地手工/日/周/月定时备份、7/30/90 天或永久保留，以及可选 S3 兼容私有
  对象存储同步。
- Web 按日期下载、上传和恢复备份；恢复采用当前密码验证和第二次手工确认。

## 4. 明确不做

- 二维码、扫码、NFC、条码识别。
- 多用户、角色权限和分享。
- 保修、价值、保险、统计分析和报表。
- 公网访问和 ClawHub 分发。
- 在本服务内实现自然语言理解或对话式消歧。

## 5. 核心业务规则

- R1：位置是树，显示路径格式为 `房间-家具-格子/容器`。
- R2：路径字符串以半角 `-` 分隔；节点名内禁止 `-`。
- R3：按路径记录物品时，不存在的位置节点必须在同一事务中自动创建。
- R4：位置含子位置或直接关联物品时，删除必须返回冲突并说明原因。
- R5：同名物品允许存在。创建接口始终新建；upsert 有 `item_id` 时精确更新，无 ID 时只有唯一名称/别名命中才更新位置，并保留主名称及请求未提供的别名/备注。
- R6：无 ID upsert 多候选时返回 `409` 和候选，不修改数据；无命中时创建。
- R7：别名与名称同等参与查询；模糊查询不得猜测不存在的数据。
- R8：物品当前位置发生变化时自动写一条含原路径、新路径和时间的历史。
- R9：一物只有一张当前照片；新照片原子替换旧照片；删除物品时删除照片。
- R10：OpenClaw/Agent 使用长期 Bearer token；Web 使用 30 天 HttpOnly 签名会话；`/health` 公开；照片使用一小时有效的签名 URL。
- R11：token 首次启动自动生成，只写入数据目录 `api-token`，权限为当前用户可读写；日志只记录路径和 SHA-256 指纹。
- R12：v1 响应字段只增不减。
- R13：Web 只有一个固定管理员账号，初始账号/密码为 `admin/admin`，密码可在登录后修改；新密码至少 8 位。
- R14：脑图默认展示位置树前两级，位置节点可逐级展开；点击物品节点弹出物品完整信息。
- R15：备份管理只允许 Web 管理员会话访问，Agent Bearer token 不得访问。
- R16：Web 恢复覆盖位置、物品、历史和照片，但保留当前 API token、管理员账号/
  密码、云配置和定时设置；恢复前自动创建紧急备份。
- R17：备份包不做客户端加密；云同步仅允许 HTTPS 私有 Bucket，并请求服务端
  AES-256 加密。云密钥只保存在本地 `0600` 配置文件且不进入备份。

## 6. 角色与数据范围

| 角色 | 可查看范围 | 可执行操作 | 禁止操作 |
|---|---|---|---|
| Web 管理员 | 全部位置、物品、历史、脑图和照片 | 账号登录后执行全部 Web 管理操作、修改密码 | 绕过非空位置保护 |
| 持有 token 的 OpenClaw/Agent | 全部位置、物品、历史和照片 | 全部 v1 业务操作 | 绕过非空位置保护 |
| 未认证访问者 | 健康状态、静态 Web 壳、有效签名照片 | 健康检查；在有效期内读取指定照片 | 读取或修改业务数据 |

## 7. 关键失败与边界场景

- 同名/别名命中多条：返回结构化候选，由 OpenClaw 追问。
- 模糊位置文本无法唯一解析：返回位置候选，不自动选择。
- 上传内容不是支持的图片、图片为空或超过 15 MiB：拒绝且不改变现有照片。
- 数据库或照片写入失败：请求失败并保留可恢复的一致状态。
- token 缺失、格式错误或不匹配：返回 401，不回显任何凭据。
- Web 账号或密码错误、会话过期或密码修改导致旧会话失效：返回 401，不说明账号是否存在。
- 签名照片 URL 过期或被篡改：返回 403。

## 9. 已确认决策

- 技术栈：FastAPI + 标准库 SQLite + 原生 HTML/CSS/JS。
- 默认端口：8733（2026-07-23 在开发机检查为空闲）。
- 开源许可证：MIT。
- 照片访问：短时签名 URL，有效期一小时。
- token 日志冲突以不泄露 Secret 为优先：日志不打印明文。
- Web 认证与 Agent 认证分离：浏览器不再读取 API token。
- 云对象存储：统一采用 S3 兼容接口，支持阿里云 OSS、腾讯云 COS 和通用 S3。
- 备份加密：不做客户端加密，使用私有 Bucket、HTTPS 与云端服务端加密。
