# ADR-0003：定时与云对象存储备份

状态：已接受
日期：2026-07-24

## 决策

- 日常管理由 Web 提供手工、日、周、月备份和 7/30/90 天或永久本地保留。
- 不新增调度框架；单进程内使用守护线程每 30 秒检查持久化时间槽，时间槽幂等。
- 云端统一使用 boto3 的 S3 兼容接口，覆盖阿里云 OSS、腾讯云 COS 与通用 S3。
- 备份包不做客户端加密；强制 HTTPS，要求私有 Bucket，并在上传时请求
  `AES256` 服务端加密。
- 云凭据只写入数据目录 `backup-config.json`，权限 `0600`，不进入备份。
- Web 恢复仅恢复业务数据，保留当前管理员身份、API token 和备份配置；以密码
  验证票据和第二次确认限制误操作，并先创建紧急备份。

## 依据

阿里云官方文档确认 OSS 提供 Amazon S3 API 兼容能力且应使用虚拟主机风格；
腾讯云官方文档确认 COS 提供 S3 兼容实现。相比同时引入两套厂商 SDK，boto3
减少配置、测试和长期维护分支。当前固定 `boto3==1.43.55` 及完整传递依赖，
支持项目 Python 3.12–3.14。

## 后果与回滚

云功能增加约一组 AWS SDK 依赖，但本地备份不依赖云连接。关闭云同步即可完全
退回本地模式；删除 boto3 依赖和云适配方法不会影响 ZIP 格式或本地恢复。
